# 🎨 p5.js Color Grid Art

This is my first creative coding project built using p5.js in VS Code.
The project generates a colorful grid of square boxes on a canvas, creating a simple generative art piece.

---

## ✨ Features

* 🎨 Dynamic color-filled squares
* 🧩 Grid-based layout
* ⚡ Built using p5.js (JavaScript library for creative coding)
* 🖥️ Runs directly in the browser
